# Estado de Chately

Página pública con el estado de la plataforma: https://estado.chately.net

**No se edita a mano.** La publica sola la plataforma (`chately-api/apps/notifications/status_page.py`) cada vez que
el equipo abre, actualiza o resuelve un incidente. Vive aquí, fuera de Cloudflare (Pages de GitHub y DNS en Hetzner),
para que siga cargando aunque Chately no cargue. No borres el archivo `CNAME`: es el dominio de la página.
